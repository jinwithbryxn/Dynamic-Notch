# 미지원·미완료 기능 목록 (notchy-parity)

이 문서는 `FEATURE-MATRIX.md`의 구현 상태 열에서 끝까지 되지 않은 행을 모아, 왜 그런지와 지금 쓸 수 있는 대안 또는 풀리는 조건을 적는다. 기준은 2026-11-02 통합 빌드(커밋 `f892ef1`, `a2911b6`, AI·개발자 묶음을 병합한 뒤의 `a31b8ec`)이고, 근거는 기능 묶음 10개의 최종 보고서, `CHANGES.md`, `a31b8ec` 빌드의 `--module-selftest=all` 결과(기능 76개, 실패 0)다. 검토용 빌드에는 손쉬운 사용·화면 기록 같은 권한이 하나도 없어서, 권한을 준 실제 Mac에서 확인한 행은 아직 없다. 따라서 "구현 · 자체 검사 통과"도 실제 사용 환경에서 확인했다는 뜻이 아니다. 대응표의 상태별 행 수는 구현 · 자체 검사 통과 71, 구현 · 실기 미검증 81, 부분 구현 72, 보류 39, 폐기 확인됨 5, 기존 기능(검증 필요) 46, 미구현 17이다(모두 331행).

## 6. AI·개발자 기능 묶음 반영

AI·개발자 기능 묶음(로컬 API, 딥링크, 코딩 에이전트, AI 사용량, 셸 활동, 터미널, 기기 안 AI 글 도구, Ask Claude)은 커밋 `0464add`로 병합됐고, 코어 연결은 `a31b8ec`에서 했다. 딥링크는 `DeepLinkModule.handle`을 거쳐 기능별 처리기로 가고, 상세 카드의 버튼(승인 허용·거부)이 코어에서 보이며, 에이전트·셸 활동이 상시 활동 순서에 들어갔다. 이 묶음의 보고서와 `a31b8ec` 빌드의 자체 검사로 K 행과 M-E-014의 상태를 정했고, 다 되지 않은 행은 1–5절에 나눠 넣었다. M-K-028은 이 묶음이 아니라 시스템 묶음의 `ports`가 맡는다.

- 이 묶음의 기능 8개(`localapi`, `deeplink`, `agents`, `localusage`, `shellactivity`, `terminal`, `aitext`, `askai`)는 모두 꺼진 채 시작한다.
- Claude 사용량의 5시간 창과 비용은 로컬 세션 기록으로 낸 추정이다. 실제 5시간·주간 게이지는 보류다(2절 M-K-002).
- 자체 검사는 훅 설치·제거와 `.zshrc` 연결을 실제 설정 파일의 사본에서만 했다. 실제 파일 4개(`~/.claude/settings.json`, `~/.codex/hooks.json`, `~/.codex/config.toml`, `~/.zshrc`)는 검사 전후로 내용이 같았다.

## 7. 풀리는 조건이 코어 작업인 항목

기능 묶음은 자기 폴더 밖을 고치지 않았으므로, 아래 코어 작업이 끝나야 풀리는 부분이 있다.
